# Mattarello — сайт итальянского гастро-бистро

Концепт для портфолио: сайт вымышленного современного бистро в Москве — свежая паста и вино дня по бокалам.

**Страницы**
- `index.html` — главная: первый экран, концепция, вино дня, подбор вина к пасте, афиша винных вечеров, бронирование, контакты.
- `menu.html` — меню с разделами, фильтром «вегетарианское» и фото паст.

**Что внутри**
- Чистые HTML, CSS и JavaScript, без сборки и зависимостей — GitHub Pages отдаёт файлы как есть.
- Mobile first, одна адаптивная вёрстка (переход на десктоп с 900 px).
- Дизайн-система: тёмная палитра noir / bordeaux / cream с латунными акцентами, Cormorant Garamond + Manrope (Google Fonts).
- Интерактив: подбор вина к пасте, вкладки меню (ссылки вида `menu.html#pasta`), фильтр, мобильное меню, демо-форма брони, появление блоков при скролле с учётом `prefers-reduced-motion`.

**Запуск локально** — открыть `index.html` в браузере или `python3 -m http.server` в папке проекта.

Все фото сгенерированы ИИ. Адрес, телефон, цены и события вымышлены. Форма брони — демо, данные никуда не отправляются.
